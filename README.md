# Salão de Beleza | Landing Page

Landing page responsiva para salão de beleza, com foco em apresentação dos serviços, galeria de trabalhos e conversão via WhatsApp.

## Visão Geral

Este projeto é uma página institucional moderna para um salão de beleza, com layout limpo, visual elegante e otimizado para celular, tablet e desktop. A estrutura foi pensada para destacar serviços, diferenciais e facilitar o agendamento pelo WhatsApp.

Inclui:

- Hero section com chamada para ação
- Seção “Sobre”
- Cards de serviços
- Galeria de trabalhos
- Seção de contato e localização
- Botão flutuante de WhatsApp
- Menu mobile responsivo
- Design leve e fácil de personalizar

## Tecnologias

- HTML5
- CSS3
- JavaScript Vanilla
